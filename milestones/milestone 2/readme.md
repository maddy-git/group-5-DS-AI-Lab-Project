**business info.pdf**
Contains all company-level operational policies for our simulated brand Clothing Retail.
It includes detailed sections on Returns, Refunds, Exchange, Shipping, Payments, Gift Wrapping, and Open-Box Delivery, written in a realistic corporate tone inspired by platforms like Myntra and AJIO.
This document demonstrates an understanding of retail operations and how policies influence customer satisfaction and logistics efficiency.

**dataset info and EDA.pdf**
Includes the dataset description and exploratory data analysis (EDA) performed on the iMaterialist dataset.
Since the original dataset is ~72 GB with 721 k+ rows, we analyzed a sample of 2,000 rows using Hugging Face streaming in Colab.

**iMaterialist_dataset_sample.csv**
The sample dataset (2,000 rows) used for EDA.
It includes columns such as image_url, gender, color, material, pattern, neckline, style, and category.
This file enables quick experimentation and visualization without loading the full dataset.
